# Folder Link Handler

Мощный плагин для Obsidian, добавляющий расширенную поддержку ссылок на папки и файлы. Переходите к папкам в дереве файлов, открывайте их в системном проводнике, используйте автодополнение путей, настраивайте цвета ссылок и многое другое.

## Возможности

- 📂 Переход к папкам в дереве файлов с автоматическим раскрытием
- 🗂️ Открытие папок в системном проводнике (только десктоп)
- 📄 Открытие файлов внешними программами (только десктоп)
- ✨ Автодополнение путей в редакторе
- 🎨 Настраиваемые цвета для ссылок на папки и файлы
- 🔴 Индикация битых ссылок с подробными подсказками
- 🔧 Правила модификации путей с использованием регулярных выражений
- 📝 Поддержка синтаксиса Markdown и Wiki
- 🔗 Множественные ссылки в одной строке с корректной обработкой кликов
- 🌍 Русский и английский интерфейс с автоопределением
- 💾 Импорт/экспорт настроек
- 📱 Совместимость с мобильными устройствами (с некоторыми ограничениями)
- ⌨️ Поддержка модификаторов клавиш (Ctrl+клик)
- 🧩 Настраиваемый префикс протокола

## Установка

### Ручная установка

1. **Найдите папку вашего хранилища.** Это директория, где хранятся ваши заметки Obsidian. Например:
   - Windows: `C:\Users\ВашеИмя\Documents\МоёХранилище`
   - macOS: `/Users/ВашеИмя/Documents/МоёХранилище`
   - Linux: `/home/ВашеИмя/Documents/МоёХранилище`

2. **Откройте скрытую папку `.obsidian`** внутри вашего хранилища. Если она не существует, создайте её.

3. **Найдите или создайте папку `plugins`** внутри `.obsidian`.

4. **Создайте новую папку** внутри `plugins` с именем `folder-link-handler`.

5. **Скопируйте файлы плагина** в папку `folder-link-handler`:
   - `main.js`
   - `manifest.json`

6. **Перезагрузите Obsidian.** Это можно сделать, нажав `Ctrl+P` и введя "Перезагрузить приложение без сохранения", или полностью перезапустив Obsidian.

7. **Включите плагин.** Перейдите в Настройки → Плагины сообщества → Установленные плагины → найдите "Folder Link Handler" → включите его.

### Структура файлов

После установки структура папок должна выглядеть так:

```
МоёХранилище/
└── .obsidian/
    └── plugins/
        └── folder-link-handler/
            ├── main.js
            └── manifest.json
```

## Использование

### Форматы ссылок

Плагин использует настраиваемый префикс протокола (по умолчанию: `folder`) для идентификации ссылок на папки.

**Формат Markdown:**

```markdown
[Моя папка](<folder:/путь/от/корня/хранилища>)
[Моя папка](<folder:./относительный/путь>)
[Моя папка](<folder:../родительская/папка>)
```

**Формат Wiki:**

```markdown
[[folder:/путь/от/корня/хранилища|Моя папка]]
[[folder:./относительный/путь|Моя папка]]
```

**Ссылки на файлы (открытие во внешней программе):**

```markdown
[Документ](<file-ext:/путь/к/файлу.pdf>)
[Документ](<file-ext:./документ.pdf>)
```

### Важно: угловые скобки

Для формата Markdown весь контент ссылки (префикс и путь) должен быть обёрнут в угловые скобки `<...>`. Это **обязательно** для путей с пробелами и рекомендуется для всех путей.

```markdown
✅ [Папка](<folder:/Мои документы/Проект>)
❌ [Папка](folder:/Мои документы/Проект)  ← Не отрендерится в режиме чтения
```

### Специальные символы в путях

Пути могут содержать скобки, точки и другие специальные символы:

```markdown
[Программы](<folder:/Программы/Приложение-v1.0(x64)>)
```

Скобки в путях обрабатываются как часть пути, а не как разделители ссылки.

### Автодополнение

Начните вводить `[Текст](folder:` в режиме редактирования, и появится список папок. Выбранный путь автоматически оборачивается в `<...>` (если включено). Курсор перемещается за закрывающую скобку.

### Команды

- **Вставить ссылку на папку** — открывает диалог выбора папки. Доступна из палитры команд (`Ctrl+P`).
- **Копировать как folder-ссылку** — кликните правой кнопкой мыши на папке в дереве файлов и выберите этот пункт из контекстного меню.

## Реализованные функции

### Основной функционал

1. **Автодополнение путей** — показывает список папок при вводе `[текст](префикс:` в редакторе. Работает только для формата Markdown.

2. **Команда «Вставить ссылку на папку»** — открывает диалог выбора папки из палитры команд. Поддерживает форматы Markdown и Wiki.

3. **Поддержка модификаторов клавиш** — `Ctrl+клик` (Windows/Linux) или `Cmd+клик` (macOS) выполняет альтернативное действие. Например, если действие по умолчанию — «раскрыть в дереве», то Ctrl+клик откроет папку в системном проводнике.

4. **Поддержка вики-синтаксиса** — оба формата (Markdown и Wiki) поддерживаются для кликов. Автодополнение работает только для формата Markdown.

5. **Индикация битых ссылок** — если папка или файл по ссылке не существует, ссылка помечается пунктирным подчёркиванием. При наведении курсора появляется подсказка с причиной.

6. **Команда «Копировать как folder-ссылку»** — кликните правой кнопкой мыши на папке в дереве файлов, чтобы скопировать её путь как ссылку на папку.

7. **Цвета ссылок** — можно задать разные цвета для ссылок на папки и файлы. Битые ссылки могут иметь свой цвет.

8. **Абсолютные пути от корня хранилища** — пути, начинающиеся с `/`, обрабатываются как абсолютные пути от корня хранилища.

### Дополнительные функции

- **Настраиваемый префикс протокола** — измените префикс `folder:` по умолчанию на любую другую строку.

- **Протокол ссылок на файлы** — протокол `file-ext:` открывает файлы внешними программами с использованием обработчика ОС по умолчанию.

- **Правила модификации путей** — регулярные выражения для модификации путей перед передачей их внешним программам. Поддерживают литеральный режим и флаги.

- **Кроссплатформенная нормализация слешей** — слеши автоматически нормализуются под вашу ОС (Windows использует `\`, остальные — `/`).

- **Поддержка ленивой загрузки дерева** — папки вне зоны видимости дерева файлов корректно раскрываются с использованием внутреннего метода `revealInFolder`.

- **Обработка угловых скобок** — пути с пробелами корректно обрабатываются при обёртывании в угловые скобки.

- **Скобки в путях** — пути, содержащие скобки, корректно парсятся с использованием посимвольного парсера с отслеживанием глубины.

- **Множественные ссылки в одной строке** — когда в одной строке несколько ссылок, клик по конкретной ссылке откроет именно её (ближайшую к позиции клика).

- **Блокировка стандартного превью** — стандартное превью при наведении в Obsidian блокируется для ссылок на папки и файлы, чтобы предотвратить некорректные сообщения «файл не найден».

- **Двуязычный интерфейс** — интерфейс плагина поддерживает русский и английский языки с автоматическим определением языка системы или ручным выбором.

- **Импорт/экспорт настроек** — экспортируйте настройки в JSON-файл и импортируйте их на другом устройстве.

- **Совместимость с мобильными устройствами** — большинство функций работают на мобильных устройствах. Функции, доступные только на десктопе, чётко указаны.

- **Режим отладки** — диагностические сообщения могут выводиться в консоль для устранения неполадок.

## Конфигурация

В настройках плагина доступны:

- **Язык** — выбор языка интерфейса (Авто / Русский / Английский)
- **Префикс протокола** — настройка префикса ссылок
- **Режим отладки** — вывод диагностических сообщений в консоль
- **Поведение ссылок** — действия в режимах чтения и редактирования
- **Ctrl+клик** — инверсия поведения с модификатором клавиш
- **Формат ссылки** — формат Markdown или Wiki для вставки
- **Угловые скобки** — переключение угловых скобок для формата Markdown
- **Формат пути** — абсолютные или относительные пути для вставки
- **Автодополнение** — включение/выключение подсказок папок
- **Цвета** — битые ссылки, ссылки на папки, ссылки на файлы, цвет подсветки
- **Длительность подсветки** — как долго папка подсвечивается
- **Модификация путей** — правила для путей внешних программ
- **Импорт/Экспорт** — резервное копирование и восстановление настроек

## Поддержка мобильных устройств

Большинство функций работают на мобильных устройствах. Функции, доступные только на десктопе, чётко указаны в настройках плагина.

| Функция | Десктоп | Мобильные |
|---------|---------|-----------|
| Переход к папке в дереве файлов | ✅ | ✅ |
| Открытие папки в системном проводнике | ✅ | ❌ |
| Открытие файла внешней программой | ✅ | ❌ |
| Автодополнение путей | ✅ | ✅ |
| Команда «Вставить ссылку на папку» | ✅ | ✅ |
| Команда «Копировать как folder-ссылку» | ✅ | ⚠️ |
| Индикация битых ссылок | ✅ | ✅ |
| Цвета ссылок | ✅ | ✅ |
| Правила модификации путей | ✅ | ❌ |
| Поддержка вики-синтаксиса | ✅ | ✅ |
| Множественные ссылки в строке | ✅ | ✅ |
| Скобки в путях | ✅ | ✅ |
| Угловые скобки в путях | ✅ | ✅ |
| Модификатор Ctrl+клик | ✅ | ❌ |
| Двуязычный интерфейс | ✅ | ✅ |
| Импорт/экспорт настроек | ✅ | ✅ |
| Режим отладки | ✅ | ✅ |

**Обозначения:**
- ✅ — Полностью поддерживается
- ❌ — Недоступно
- ⚠️ — Ограниченная поддержка (может не работать на всех устройствах)

**Ограничения на мобильных устройствах:**

- Открытие папок в системном проводнике недоступно, так как мобильные устройства не имеют прямого доступа к файловой системе.
- Открытие файлов внешними программами недоступно по той же причине.
- Правила модификации путей не применяются, так как интеграция с внешними программами недоступна.
- Модификатор Ctrl+клик недоступен, так как на мобильных устройствах нет клавиатуры.
- Команда «Копировать как folder-ссылку» может не работать на всех мобильных устройствах из-за ограничений API буфера обмена.

## Известные ограничения

- Автодополнение работает только для формата Markdown. Автодополнение для формата Wiki конфликтует со встроенными подсказками вики-ссылок в Obsidian.
- На мобильных устройствах некоторые функции недоступны из-за ограничений платформы.
- Правила модификации путей применяются только при передаче путей внешним программам. Переход к папке в дереве файлов не затрагивается.
